## 연구 개요

대한민국 정치 양극화 문제를 배경으로, **20대(2016.05 ~ 2020.05) 및 21대(2020.05 ~ 2024.05) 국회의 법안 공동발의 데이터**를 소셜 네트워크 분석(SNA) 기법으로 분석하여 초당적 협력을 촉진하는 주요 요인을 다각도로 파악합니다.

---

## 연구 배경 및 목표

- 한국 성인 90%가 "한국 정치 갈등이 심각하다"고 인식 (Pew Research Center, 2021)
- 거대 양당 간 협력 법안 비율이 **12.6% → 5.7%** 로 급감 (19대 → 21대, SBS뉴스)
- 선행 연구(박찬무·장원철 2017 / 김준석 2015 / Fowler 2006 / Zhang et al. 2008)는 특정 시기 또는 여야 간 협력만을 분석하는 한계 존재

**본 연구의 차별점**

| 선행 연구 | 본 연구 |
|---|---|
| 특정 시기(17대, 19대)만 분석 | 20대 / 21대 비교 분석 |
| 초당적 협력 = 여야 간 협력으로 한정 | 모든 정당 간 협력으로 확장 |
| 커뮤니티 구조 분석 부족 | 새롭게 정의한 지표 + 해외 지표 적용 |

**연구 목표**: 20대 / 21대 국회의 법안 공동발의 네트워크를 분석하여 초당적 협력 촉진을 위한 주요 요인을 다각도로 파악한다.

## 네트워크 모델 정의

공동발의 네트워크는 다음과 같이 정의됩니다.

- **Node**: 법안 발의에 참여한 국회의원
- **Edge**: 공동발의자(source) → 대표발의자(target)
- **Directed**: 공동 발의에 참여 = 대표발의자의 법안을 지지
- **Weighted**: 공동 발의 횟수를 가중치로 부여

```
예) A 의원이 B 의원의 대표발의 법안에 4번 공동발의 → edge 가중치 = 4
```

우리나라 공동발의 제도의 특성상 **공동발의자 ↔ 대표발의자** 연결이 강하고, **공동발의자 ↔ 공동발의자** 직접 연결은 약하게 설계됩니다.

## 분석 지표

### 거시적 지표 (네트워크 수준)

#### 1. 정당 모듈러리티 / 최대 모듈러리티 비율

> "네트워크를 정당 속성만으로 구분 가능한 정도"

- **정당 모듈러리티**: 각 의원의 정당에 따라 네트워크를 군집화했을 때 내부 밀집도 / 외부 희박도를 정량화
- **최대 모듈러리티**: 모든 군집화 방식 중 최적으로 분리했을 때의 최고 수준
- **비율 = 정당 모듈러리티 / 최대 모듈러리티**
  - 1에 가까울수록 → 정당 속성의 영향력이 큼 (양극화 심화)
  - 0에 가까울수록 → 정당 외 다른 요인도 협력 관계에 영향

#### 2. 정당별 혼합성 지수 (Assortativity)

$$\text{Assortativity}(P) = \frac{\sum_{(u,v) \in E_{PP}} w(u,v)}{\sum_{(u,v) \in E_P} w(u,v)}$$

- 정당 내부 엣지 가중치 합 / 해당 정당의 전체 엣지 가중치 합
- 1에 가까울수록 → 같은 정당 의원들과만 협력
- 0에 가까울수록 → 타 정당 의원들과도 고르게 협력 (초당적)

#### 3. 정당 간 협력 지수 (Inter-party Cooperation Index)

Fowler(2006) 방법론을 기반으로 정의

$$S_{ij} = \frac{C_{ij}}{\sqrt{d_i \times d_j}}, \quad P_{AB} = \frac{\sum_{i \in A, j \in B} S_{ij}}{|A| \times |B|}$$

- $C_{ij}$: 두 의원의 공동발의 횟수
- $d_i, d_j$: 각 의원의 총 발의 횟수
- $P_{AB}$: 정당 A와 정당 B 간 협력 정도

### 미시적 지표 (노드 수준)

#### 4. 매개 중심성 (Betweenness Centrality)

- 한 노드가 다른 노드들 간 최단 경로에 얼마나 자주 포함되는지
- 높은 값 → 정당 간 브릿지 역할, 협력 촉진 가능성

#### 5. 샤넌 엔트로피 (Shannon Entropy)

$$H = -\sum_i p_i \cdot \log(p_i)$$

- $p_i$: 의원이 특정 정당과 연결한 비율
- 높은 값 → 다양한 정당과 고르게 협력 (초당적)
- 낮은 값 → 특정 정당과만 집중 협력

**매개 중심성 × 샤넌 엔트로피 조합으로 초당적 협력 핵심 의원 식별**

| | 샤넌 엔트로피 낮음 | 샤넌 엔트로피 높음 |
|---|---|---|
| **매개 중심성 높음** | 당 내부 결속 강화 | ⭐ 초당적 협력 허브 |
| **매개 중심성 낮음** | 네트워크 영향력 낮음 | 협력 다양하나 영향력 낮음 |

## 가설 및 분석 결과

### 가설 1: 중도 제3지대 정당구조 변화가 초당적 협력에 미치는 영향

> "중도의 제3정당이 존재한 시기 공동발의 법안에서 정치적 양극화가 개선되고 초당적 협력이 높아질 것이다."

20대 국회 내부를 바른미래당 창당(2018년 2월) 전후로 비교

**분석 결과**

| 지표 | 창당 이전 | 창당 이후 |
|---|---|---|
| 정당 모듈러리티 | 0.4664 | 0.4661 |
| 최대 모듈러리티 | 0.4690 | 0.5037 |
| **비율** | **0.9944** | **0.9255** |

- 창당 이후 비율 감소 → 정당이라는 단일 속성이 협력 패턴을 완벽히 설명하지 못하게 됨
- 혼합성 지수: 제3지대(국민의당 0.5550 → 바른미래당 0.3494) 하락 → 외부와 활발히 소통
- 정당 간 협력 지수: 바른미래당이 창당 후 자유한국당 및 민주당 모두와 협력 채널 형성
- 제3정당 대표발의 법안에서 거대 양당 동시 협력: 국민의당 18.04% → 바른미래당 21.69%

**결론**: 중도 정당의 탄생은 초당적 협력 증가 가능성을 보여줬으나, 내부 결속력 부족으로 지속 가능성 확보 실패 → 중도 정당의 초당적 효과는 일시적

---

### 가설 2: 소관위원회별 초당적 협력 차이

#### 가설 2-1 (거시적)
> "저출생, 교육 등 시의성이 높고 긴급한 사안을 다루는 소관위원회 공동발의에서 초당적 협력이 더 활발하다."

**분석 결과 — 정당 모듈러리티 비율이 낮은 위원회 (20대, 21대 공통)**

| 소관위원회 | 특성 |
|---|---|
| 정보위원회 | 초당적 안보 협력 필요 |
| 여성가족위원회 | 저출생 등 시급한 사회문제 |
| 문화체육관광위원회 | 이념 갈등 가능성 낮고 국민 공감대 형성 용이 |

- 반면 **정무위원회**(금융·경제 규제)는 비율 0.98로 높음 → 정당 간 의견 차이가 심한 분야

**정의당 분석**: 정의당은 동일 당 의원 간 협력지수가 낮고, 타 정당과의 협력지수가 높게 나타남 → 안건 내용 중심 협력 비중 높음 (다수당은 당론에 좌우)

#### 가설 2-2 (미시적)
> "전문성과 경험 많은 의원들이 초당적 협력에서 중요한 역할을 한다."

**분석 결과**
- 학과·특기 등 전문성과 소관위원회 배치의 상관관계는 낮음
- **선수별 분포**: 소관위원회 초당적 협력 Top5 의원 중 5선/6선 의원 비율이 초선/재선, 3~4선에 비해 낮음
  → 초당적 협력을 위한 중진 의원들의 적극적 참여 필요

## 결론

| 요인 | 분석 결과 |
|---|---|
| 제3지대 중도 정당 | 중도 정당이 거대 양당을 매개로 초당적 협력을 촉진하나, 내부 결속력 부족 시 일시적 효과에 그침 |
| 법안 분야 (소관위원회) | 시의성 높고 이념 갈등이 낮은 분야(여성·가족, 문화·체육, 정보)에서 초당적 협력이 활발 |
| 의원 경험 (선수) | 5선/6선 중진 의원의 초당적 협력 참여율이 낮아 개선 필요 |

**정책적 시사점**
1. 지속 가능한 중도 정당이 가능하다면 초당적 협력을 꾸준히 촉진할 수 있을 것
2. 거대 양당은 시의성이 높은 법안을 정쟁의 대상으로 삼지 말고 안건 중심의 협력을 이루어야 함
3. 초당적 협력을 위한 중진 의원들의 적극적인 참여가 요구됨

## 한계

1. 각 분석 시기의 내·외부적 정치적 변화(소수 정당 탄생, 사회적 갈등, 경제 위기 등)가 네트워크 형성에 미치는 영향 미반영
